```text
/mechanic-forge-source
> follow https://simonwillison.net/atom/everything/ daily into intelligence/ai
```

```bash
python3 script.py --type=atom --url=https://simonwillison.net/atom/everything/ \
  --cadence=daily --target-pillar=intelligence --target-topic=ai
```

Appends a YAML block keyed by url to `anatomy/playbooks/intelligence/sources/core.md`. Dedup by normalized url. Plugins pass `--contributor=<plugin>` to write their own file.

## Classify a drop

A file dropped in `_ingest/` triggers the `gilberto-process-ingest` launchd job (loaded on the skill's first run, once the skill is installed). It classifies the file into a pillar and hands it to `gilberto-capability-<pillar>-archive`; the file lands in the pillar with an `.ingest.json` sidecar and leaves `_ingest/`. Low confidence, unsupported or unclassifiable files stay (errors get an `.error.md`).
