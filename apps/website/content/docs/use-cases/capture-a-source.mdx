---
title: Capture a source
description: Register a feed, channel or device as an ingestion source.
---

```text
/mechanic-forge-source
> follow https://simonwillison.net/atom/everything/ daily into intelligence/ai
```

```bash
python3 script.py --type=atom --url=https://simonwillison.net/atom/everything/ \
  --cadence=daily --target-pillar=intelligence --target-topic=ai
```

Appends a YAML block keyed by url to `anatomy/playbooks/intelligence/sources/core.md`. Dedup by normalized url. Plugins pass `--contributor=<plugin>` to write their own file.
