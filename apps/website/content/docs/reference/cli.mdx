The CLI (`npm: gilberto`) is install/update tooling only; the vault never needs it at runtime.

## Global options

| Option | Effect |
| --- | --- |
| `-V`, `--version` | print version |
| `--log-level <level>` | `debug` · `info` · `warn` · `error` |
| `-v`, `--verbose` | alias of `--log-level debug` (deprecated) |
| `--no-banner` | suppress the banner |
| `--json` | structured output (suppresses the banner) |

## `gilberto install [target]` — available

Bootstrap a vault. Flags, wizard steps and exit codes: [Install](/docs/getting-started/install).

```bash
gilberto install ~/vault --seed-topics "intelligence=ai,product;pulse=health"
gilberto install ~/vault --non-interactive --no-launchd
```
